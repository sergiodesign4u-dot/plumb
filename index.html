Plumb

A number you can defend

Plumb is a metric trust tool for B2B teams. It keeps the canonical definition of every metric in one place and shows, right next to the number, where that number came from, how fresh it is and what changed since it was last read.

This repository holds the whole design pipeline, thirteen stages. Every stage adds its documents and its own page. The list below is rendered from the same navigation registry the sidebar uses, so a stage appears here the moment it is marked done.
