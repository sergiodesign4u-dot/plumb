Node 4.6, the definition does not run, in its blocking form. Three things at once, and they are not alternatives: a banner at the top saying the attempt failed, an inline message on the field that caused it in the warehouse's own words, and the form still filled in. The banner alone leaves the analyst hunting for the field, the inline message alone can be scrolled past, and a form that empties itself turns a typo into retyping a definition. The node names three failure modes and only two of them are drawn here. The second blocking one is a query that came back with more than one row or column, where the message says that a metric is one value and what came back instead. The third is not an error at all: a query that ran and returned nothing is a warning and does not block, because a metric can legitimately be empty right now and blocking would stop somebody defining a metric before the data exists. That is the same distinction node 0.4 draws for the reader, where empty is a state rather than an error and never a zero. Interface wording is draft, stage 05 owns it.
