Node 1.1, the gate, and flow 4 step D1. Blocks in the order the node fixes: product name, heading, one field, one action, the notice slot, the legal line, the footer. No header, because a gate is seen by a guest and the global navigation of node 0.1 belongs to the analyst's screens. No password field, no reset, no GitHub or Google button, no create an account and no language selector, each of them a decision the node records rather than a gap: the stack commits to OIDC and SAML through a provider, so a password we do not use would only be an attack surface with a support queue attached. The action stays enabled and answers on submit, which is what makes 1.3 reachable at all. The notice slot is present in the block order and empty here, since it is used only when there is something true to say before the action. The three footer targets are pages this round does not draw, so the footer renders them as text. Interface wording is draft, stage 05 owns it.
