How is a definition written?

A definition in Plumb is a sentence, not a formula. It says what the metric counts, on what, and over what period, in words somebody outside the data team can check.

The query underneath it is what makes it executable, and the reader never sees it. When the definition changes, everybody holding a link to that number is told what it used to say.

Weekly active accounts, as it stands today: distinct accounts with at least one session in the last 7 days, counted on the account, not the user. Declared by Dana Reyes, Analytics, on 3 August.

What do the states beside a number mean?

Three states, and there is no fourth. A number with nothing wrong carries its age, not a badge saying it is fine.

As of
The query ran and returned a value. The card says how old it is and what cadence is expected: as of 14:05, 20 minutes ago, expected hourly.
Source is down
The source could not be reached when you opened the card. You still get the definition, the owner and the last successful run. No value at all, because we keep no copy of it.
Definition changed
The current definition differs from the one your link carried. You get the current value, the current definition and what it used to say.
The query returned nothing
The query ran and no rows came back. You get the definition, the owner and the time it ran, and never a zero.

More than one can be true at once, and both are shown. A source that is down and a definition that changed appear together, the source first. An empty result and a changed definition appear together, the empty result first. A source that cannot be reached cannot return an empty result, so that pair never happens.

No state carries a severity, an owner to chase or anything to close, and no score is computed from them. A state ends when the fact underneath it ends.
